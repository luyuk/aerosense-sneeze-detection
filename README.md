# aerosense-sneeze-detection
AeroSense adalah purifikasi udara cerdas berbasis TinyML yang otomatis aktif saat mendeteksi suara bersin secara lokal tanpa internet. Mengutamakan privasi tanpa menyimpan audio mentah, sistem ini memiliki akurasi 97,5% dan hemat energi hingga 71,4%, menjadikannya solusi ideal yang berkelanjutan untuk ruang kelas pintar.
